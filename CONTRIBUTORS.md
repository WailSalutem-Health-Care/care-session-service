## Project Overview

Care Session Service is a FastAPI-based microservice for managing care sessions in the WailSalutem healthcare platform. It handles:

- **Care Session Management**: Creating, updating, and tracking care sessions
- **NFC Integration**: Processing NFC tag scans for session initialization
- **Feedback & Satisfaction**: Collecting patient feedback and satisfaction ratings
- **Reporting**: Generating analytical reports on care sessions and caregiver performance
- **Multi-tenancy**: Supporting multiple healthcare organizations with isolated data
- **Event-Driven Architecture**: Publishing and consuming events via RabbitMQ
- **Observability**: Comprehensive logging, metrics, and distributed tracing
